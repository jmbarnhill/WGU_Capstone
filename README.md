# WGU_Capstone
Repository to hold the capstone project submitted to Western Governors University to fulfill the degree requirements for a Master of Science in Data Analytics.

# File Descriptions

Barnhill_Executive_Summary: Summary document detailing the overall premise and findings of the project

Barnhill_Capstone_Report: Full report detailing data collection, analysis, and findings

Barnhill_Capstone_Slides: PDF printout of PowerPoint presentation included with submission

Project_Assets Folder: Includes the complete Python code used for the project in a Jupyter Notebook  - Barnhill_Capstone_Code.ipynb, as well as all .csv files containing project data
